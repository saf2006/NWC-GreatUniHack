NWC: NatWest Count 
Your money. Your future. Make every penny count.

Big purchase? Big decision? NatWest Count helps you crunch the numbers, spot financial risks and plan for a more secure tomorrow.
1) Inspiration
Financial guidance should not be a luxury. Low-income households and people with irregular incomes can face difficult choices between essential spending, saving and borrowing. Buy Now, Pay Later (BNPL), overdrafts and other forms of credit may help in the short term, but extra fees and repayments can make staying on top of money harder.

We built NatWest Count (NWC) to make financial planning clearer and more accessible — and to help people anticipate problems before they need to borrow again.
2) What NWC does
NWC is an interactive, privacy-conscious financial planning prototype that helps users:
- Understand this month's budget — see expected income, bills, savings goals and money left for everyday spending.
- Travel through their financial future — explore illustrative scenarios over months or years, including the potential impact of reducing extra costs.
- Check a purchase before buying — see whether a planned expense fits around bills, essentials and savings goals.
- Spot extra costs — identify patterns such as overdraft charges, late fees and potential poverty premiums, with practical suggestions.
- Stress-test their finances — explore what unexpected repairs, delayed income or job loss could mean for their emergency savings.
- Get guided answers — use the ai.nwc question helper, which explains personal budget figures using preset questions and transparent calculations.
- Adjust the experience — use accessibility settings including larger text, high contrast, colour-blind-friendly colours and easier-to-read formatting.
The interface includes built-in English, Spanish, Polish and French support. Additional language options can be generated locally with Ollama when a model is installed.
3) Built with
- Python — budgeting rules, financial calculations and simulations
- Streamlit — interactive web interface
- Pandas — transaction processing and categorisation
- NumPy — scenario simulation and numerical analysis
- Altair — data visualisation
- HTML/CSS — styling, animations and accessibility features
Financial calculations are handled by Python rather than generated by a language model. Forecasts are illustrative scenarios, not guaranteed predictions.
 4) Run locally
1. Download the project files
Keep these files in the same folder:
NWC-GreatUniHack/
├── app.py
├── translations.py
├── requirements.txt
└── README.md
2. Install the dependencies
Open Command Prompt or a terminal in that folder and run:
py -m pip install -r requirements.txt
On macOS or Linux, use python3 -m pip install -r requirements.txt instead.
3. Start the app
py -m streamlit run app.py
On macOS or Linux, use python3 -m streamlit run app.py instead.

Open http://localhost:8501 in your browser.
4. Try the demo
Follow the simulated bank-connection steps, choose a savings goal and select Load sample data. Alternatively, upload a CSV file with these columns:
date,description,amount
2026-09-01,AGENCY PAY,1200
2026-09-02,RENT,-500
2026-09-03,GROCERIES,-45
Use positive amounts for income and negative amounts for spending. The budgeting analysis needs at least two completed months of transaction history.
5) Privacy and limitations
- This hackathon prototype does not connect to a real bank. Its onboarding flow is simulated.
- You can explore the app with synthetic sample transactions; no bank passwords are required.
- The current ai.nwc helper uses preset questions and prewritten, data-driven answers rather than an open-ended AI chat model.
- Some visual fonts are requested from Google Fonts, so the interface may make that external request.
- Estimated cost premiums and financial forecasts use assumptions. The app provides educational guidance, not regulated financial advice.
Please use demo or non-sensitive data when sharing a public demonstration.
